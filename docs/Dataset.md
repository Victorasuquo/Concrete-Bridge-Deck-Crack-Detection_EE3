Dataset Preparation Guide
Our dataset is SDNET2018, from Utah State University.
## Which images we useThe dataset has three folders: D for bridge decks, W for walls,P for pavements. Our assigned task is bridge decks, so we onlyuse the D folder.
Inside D there are two folders:- CD  cracked decks- UD  uncracked decks



We trained the data set to recognise cracks on concrete
