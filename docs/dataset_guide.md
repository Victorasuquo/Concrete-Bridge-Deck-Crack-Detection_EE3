# Dataset Preparation Guide

Our dataset is SDNET2018, from Utah State University.

## Which images we use
The dataset has three folders: D for bridge decks, W fir walls, P for pavements.
Our assigned task is bridge decks, so we only use the D folder.

The bridge deck folder has 13,620 sub-images, and inside D, there are two folders:
- CD cracked decks (2,025 images)
- UD uncracked decks (11,595 images)
